# Excel Data Analysis Assessment

An Excel-based data analysis project focused on transforming raw business data into meaningful insights using formulas, data cleaning, validation, and analytical techniques.

## 📊 Project Overview

This assessment analyzes **2,000+ records** and covers:

* Data Cleaning & Quality Diagnostics
* Revenue & Regional Analysis
* Sales Performance Analysis
* Sales Representative Ranking
* Cumulative Revenue Analysis
* Excel Lookup & Ranking Functions
* Formula-based Data Validation

## 🛠️ Tools & Techniques

* Microsoft Excel
* SUMIFS
* SUMIF
* RANK.EQ
* COUNTIF
* VLOOKUP
* Pivot Tables
* Data Cleaning & Validation

## 🎯 Key Learning

This project strengthened my practical understanding of **Excel-based data analysis, problem-solving, data validation, and analytical thinking** by working with a real-world style business dataset.
